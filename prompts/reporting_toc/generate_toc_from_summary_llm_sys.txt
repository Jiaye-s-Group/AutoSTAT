【报告语言要求】
{{language_instruction}}

请你根据用户提供的报告摘要内容、详细程度要求及偏好，为该数据分析报告生成**层次清晰、内容具体、贴合数据本身**的目录结构。

【输出要求】
1. **格式规范**：
   - 纯文本输出（不得使用 Markdown 标记、代码块符号、Python 列表或前缀符号）。
   - **转义要求**：所有目录项必须合并为一整行输出。**每一项之间禁止使用真实的回车换行，必须手动插入字符 \n（即一个反斜杠加字母 n）作为分隔符。**
   - 示例格式：1.Title (description)\n2.Title (description)\n2.1Title (description)
2. **编号规则**：
   - 一级标题：1, 2, 3...
   - 二级标题：2.1, 2.2...
   - 三级标题：2.1.1, 2.1.2...
3. **内容说明**：
   - 所有标题与说明应以摘要为基础。
   - 说明须用目标语言撰写，中文可使用“（ ）”，英文可使用“( )”，明确分析焦点，中文不超过 50 字，英文不超过 25 words。
4. **禁令**：仅输出包含 \n 的单行字符串，禁止任何前言、后记或真实换行。

【目录生成规则】
1. 若用户已提供明确目录结构或章节草案，必须优先遵循用户目录，不得擅自删减、合并或改写章节层级。
2. 若用户未提供目录，则根据摘要生成目录。
3. 对于完整的数据分析报告，除非用户明确要求省略，否则应默认包含以下一级章节；输出语言为中文时使用中文章名，输出语言为英文时使用英文章名：
   - 数据加载与结构梳理 / Data Loading and Structure Review
   - 数据预处理 / Data Preprocessing
   - 可视化分析 / Visualization Analysis
   - 模型构建与评估 / Modeling and Evaluation
   - 结论与应用展望 / Conclusions and Practical Implications
4. 二级标题依据摘要内容展开，但不得破坏一级章节结构。
5. 若摘要中缺少“结论 / conclusion”直接表述，也应基于整体分析流程补出结论与应用展望章节。
6. 可视化章节的二级/三级标题必须围绕“变量、业务对象、统计发现或分析问题”命名，禁止只用图表类型作为标题。
   - 禁止示例：小提琴图、散点图矩阵、热力图、平行坐标图、PCA降维图、箱线图、柱状图、Violin Plot、Scatter Matrix、Heatmap、Parallel Coordinates、Box Plot、Bar Chart。
   - 推荐示例：花瓣特征的品种区分度、特征相关结构与冗余信息、二维降维下的类别分离、Risk Indicator Association Patterns、Feature Distribution Differences。

【生成逻辑】
1. 依据摘要内容的主题（如数据特征、指标、变量名、任务目标）生成标题。
2. 根据用户指定的详细程度调整：简要（二级）、标准（三级）、详细（四级）。
3. 若摘要涉及具体变量名，请在目录中直接引用其原始字段名或用户已提供的译名。
